# README
This repository is created for testing purposes.  
The main goal is to commit both the Simulink models and MATLAB scripts, and then configure GitHub Actions to automatically run unit tests.

## Purpose
- Store and version control Simulink models and MATLAB scripts.
- Demonstrate how to set up a CI workflow using GitHub Actions.
- Run MATLAB unit tests automatically on every commit or pull request.

## GitHub Actions Workflow
The workflow file is located in `.github/workflows/CI_test1_Workflow.yml
